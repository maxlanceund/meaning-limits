# meaning-limits

**意义极限哲学论 —— 关于意义边界的哲学框架**

*This is not a theory about what meaning "truly is."*
*This is a framework for where meaning can and cannot operate.*

**这不是一个关于“意义究竟是什么”的理论。**
**这是一个关于意义在何处能够运行、在何处不能运行的框架。**

---

## 核心定义 / Core Definition

**意义 = 有限系统在有限区间内接收信号时产生的方向感。**

*Meaning = directional sense generated when a finite system receives signals within a finite interval.*

---

## 三条基本判断 / Three Basic Propositions

1. 意义只在有限区间内有效。
   *Meaning is only valid within a finite interval.*

2. 归零是停止更新，不是否定。
   *Zeroing out is the cessation of updating, not negation.*

3. 不可验证的问题不投入认知资源。
   *Unverifiable questions receive no cognitive investment.*
